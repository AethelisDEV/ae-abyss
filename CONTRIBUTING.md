# Contributing to AE Abyss

First of all, thank you for wanting to contribute to AE Abyss! This project is an open-source local AI tool that grows stronger with community help.

## How Can You Contribute?

1.  **Bug Reporting:** If you find a bug, please report it via GitHub Issues.
2.  **Feature Requests:** Have a new idea? Open a Discussion or share it via an Issue.
3.  **Code Contribution:**
    - Fork the project.
    - Create a new branch (`git checkout -b feature/newfeature`).
    - Make your changes and test them.
    - Submit a Pull Request (PR).

## Code Standards

- **Rust:** The project uses Rust 2024 edition. Ensure your code passes `cargo fmt` and `cargo clippy` checks.
- **Comments:** Don't forget to add explanatory comments for complex logic.
- **Language:** All code, comments, and system prompts must be in English.

## Pull Request Process

- Your PR title should be short and descriptive.
- It's always better to open an Issue and discuss large changes before implementing them.
- PRs are merged into the main branch after code review.

Thanks! 🚀
